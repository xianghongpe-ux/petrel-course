## 📋 指南概述

本文档指导社区运营者和早期贡献者如何启动海燕党第一批种子成员的招募与管理工作。目标是在首批30天内完成核心社区的组建。

---

## 🗓️ 30天启动路线图

### 第1-3天：筹备阶段

- [ ] 确认核心创始团队（3-5人作为临时委员会）
- [ ] 部署入党管理系统（见 `05-tool/membership/`）
- [ ] 初始化数据库：`python member_cli.py init`
- [ ] 配置 GitHub 仓库，创建 `membership` 模块
- [ ] 准备招募海报（`marketing/recruitment-poster.html`）

### 第4-14天：首批招募

- [ ] 发布招募海报到各社交媒体平台（文案见 `marketing/social-media-copy.md`）
- [ ] 在 GitHub 创建招募 Issue 模板
- [ ] 第一批接受5-10名申请者
- [ ] AI初审 → 委员会终审 → 通过者进入考察期
- [ ] 为每名新成员分配 mentor

### 第15-21天：社区建设

- [ ] 建立微信群/Discord 频道
- [ ] 举办第一次线上见面会（介绍党纲、治理机制）
- [ ] 分配第一批社区任务
- [ ] 开始记录考察数据：`member record <id> --month 1 --study ...`
- [ ] 邀请成员阅读党纲和治理章程

### 第22-30天：扩大影响

- [ ] 收集首批成员的反馈，优化流程
- [ ] 根据首批运行情况调整 AI 初审阈值
- [ ] 开放第二批招募（目标15-30人）
- [ ] 持续考察记录与社区互动

## 👥 种子成员画像

理想的种子成员应具备以下1-2项特质：

| 类型 | 描述 | 招募渠道 |
|------|------|---------|
| **思想认同型** | 认同"AI只献策不决策"，关注AI治理伦理 | 知乎、微博、科技媒体 |
| **技术贡献型** | 愿意为开源治理系统贡献代码 | GitHub、HackerNews |
| **社区建设型** | 擅长运营、写作、社区管理 | 微信社群、博客圈 |
| **研究分析型** | 关注AI治理、政治哲学、组织形态研究 | 学术圈、研究机构 |

**多样性目标：** 首批成员中，技术背景不超过60%，确保不同视角的平衡。

## 🛠️ 运营者工具速查

### 日常操作

```bash
# 查看待初审申请
python member_cli.py list --status pending

# AI批量初审所有待处理申请
python member_cli.py review --all

# 人类终审
python member_cli.py evaluate <ID> --verdict approved --notes "委员会一致通过"

# 记录某成员第n个月考察数据
python member_cli.py record <ID> --month 1 --study 60 --tasks 3 --participation 75

# 查看考察状态
python member_cli.py status <ID>

# 生成AI评估报告
python member_cli.py eval-report <ID>

# 委员会投票转正
python member_cli.py promote <ID> --total 5 --approve 4 --reject 0 --abstain 1

# 查看统计
python member_cli.py stats

# 每日快报
python member_cli.py summary
```

### 考察期提醒

| 时间点 | 操作 |
|--------|------|
| 每月1日 | 提醒考察中成员提交上月进度 |
| 每月5日 | 运营者录入上月考察数据 |
| 第4个月末 | 评估落后成员，安排mentor谈话 |
| 第6个月末 | 生成评估报告，启动转正流程 |

## 📐 团队角色设计

```
临时委员会（发起阶段，任期6个月）
├── 主席（1人）：统筹全局，主持终审会议
├── 技术委员（1-2人）：维护治理代码系统
├── 人事委员（1人）：管理会员申请与考察
└── 运营委员（1人）：社区活动与对外联络

正式委员会（第一批转正后选举产生）
├── 由正式党员选举，任期12个月
├── 席位5-9人
├── 每月一次公开会议
└── 所有会议记录开源
```

## 🔒 治理原则备忘

1. **AI只献策不决策** — 任何AI生成的评估报告仅供委员会参考，不具有决定权
2. **全流程透明** — 所有考核数据、评分逻辑、评估报告均在GitHub开源
3. **一人一票** — 正式党员拥有平等的投票权
4. **可退出** — 任何成员可随时退党，流程透明
5. **迭代优化** — 治理机制本身也通过社区提案改进

## ⚠️ 常见问题

**Q: 如何确保AI初审公正？**
A: AI评分逻辑完全开源（`evaluation_report.py`），任何人均可审查。AI判定仅为"建议"，最终由人类委员会决定。

**Q: 考察期的具体标准是什么？**
A: 详见 `candidate_tracker.py`。每月学习进度≥16%、完成任务≥2个、参与度≥30%为基本达标线。

**Q: 早期委员会如何产生？**
A: 创始团队成员组成临时委员会，待第一批成员转正后通过民主选举产生正式委员会。

**Q: 退党有什么后果？**
A: 退党后个人数据按照隐私政策处理。退党记录保存在数据库中用于治理统计，不会对外公开。
