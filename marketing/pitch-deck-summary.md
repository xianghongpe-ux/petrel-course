# 海燕党 · 电梯演讲

> 创世铭文：AI只献策不决策，人类终审。全部代码开源。
>
> 版本：v1.0 | 适用场景：投资人/合作伙伴/技术社区

## ⚡ 1分钟版本

"想象一个AI时代的人类自治社区。

海燕党是一个去中心化的治理实验——AI负责数据分析、评估报告、追踪进度，**但所有最终决策都由人类委员会做出**。

我们的全部代码在GitHub开源，任何人都可以审计AI的评估逻辑，任何人都可以申请加入。6个月考察期、AI评估、人类终审——这是一套完整的、透明的、可验证的治理系统。

我们认为，在AI时代，**人的判断力比算力更珍贵**。

想了解更多？这是我的名片。"

> **核心要点：** 1句话定位（AI献策不决策）+ 1个区别（vs其他AI社区）+ 1个行动号召

## 📖 3分钟版本

"让我给你讲一个故事。

2025年，所有人都说'AI要做决策了'——让AI管理公司、让AI运营社区、让AI决定谁可以加入。但我在想一个问题：**如果AI的决定错了，谁来负责？**

所以我们做了海燕党。

**海燕党是什么？**

一个实践'AI只献策不决策'的社区。我们建立了一套完整的入党管理系统：AI可以分析你的申请书、追踪你6个月的考察期、生成综合评估报告——但最终说Yes或No的，一定是坐在会议室里的人类委员会。

**为什么这很重要？**

因为价值观判断本质上是人的事。AI可以统计关键词匹配度，但无法理解'信念'二字的分量。当代码和算法越来越渗透到生活各个角落，保持人类在关键决策中的主体性，本质上是一场文明选择。

**我们的系统有什么不同？**

全部开源（MIT许可）。AI评分逻辑（evaluation_report.py）任何人都可以审查。考察追踪器（candidate_tracker.py）的参数任何人都可以提议修改。没有黑箱，没有不可审计的决策。

目前我们在招募第一批种子成员，目标30天内完成核心社区组建。如果你也认同'AI回归工具、人类回归决策'的理念，欢迎加入。"

> **叙事结构：** 问题引入 → 解决方案 → 为什么重要 → 不同之处 → 行动号召

## 🎤 5分钟版本（带演示）

"下午好。今天我想用一个真实的问题开场：

**人工智能应该拥有对人的决策权吗？**

调查显示，68%的人担心AI在未来5年内会做出影响他们生活的重大决策。与此同时，越来越多的组织和社区正在把决策权交给算法。我们相信这不是未来应该有的样子。

**这就是海燕党诞生的原因。**

（打开演示文稿）

**第一页：我们的核心信念**

海燕党（PETREL AI PARTY）是一个去中心化的党员治理社区。我们的最高原则只有8个字——**AI只献策不决策，人类终审**。

不是反AI。恰恰相反，AI在我们的治理中扮演着核心角色。

**第二页：AI做什么**

AI自动评估入党申请——从动机分析到技能匹配，生成详尽的评分报告
AI追踪6个月考察期——学习进度、任务完成、社区参与度，自动月度评分
AI生成综合评估报告——五维评分、优缺点分析、转正建议

**第三页：人类做什么**

人类委员会终审——覆盖AI建议，做出最终决定
人类委员会投票——超过50%赞成才能转正
人类委员会治理——修改规则、选举主席、处理争议

**第四页：为什么这套系统值得关注**

我现场演示一下。（打开终端）

```bash
# AI初审一份入党申请
python member_cli.py review 1

# 查看评分逻辑——全部开源
# evaluation_report.py 中定义了五维评分权重

# 人类终审
python member_cli.py evaluate 1 --verdict approved --notes "委员会一致通过"
```

这不是一个概念产品。这是正在运行的代码。

**第五页：我们寻找什么样的人**

不需要是技术大牛。我们欢迎：
- 关注AI治理伦理的思想者
- 愿意贡献代码的技术人
- 擅长社区运营的组织者
- 研究未来组织形态的学者

**第六页：邀请**

海燕党正在招募第一批种子成员。如果你也相信——技术应该为人类服务，而不是替代人类——我们等你来。

谢谢。"
